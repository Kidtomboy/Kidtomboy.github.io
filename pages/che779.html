🎮 Che779 J2ME

Giả lập game Java (J2ME) cho Windows, Linux và Android: nhiều tab, proxy theo tab, đồng bộ thao tác, dọn RAM. Dựa trên MicroEmulator 3.0.0 và J2ME Loader 1.8.2. Bản phát hành bên dưới lấy trực tiếp từ GitHub.

Đang tải bản phát hành…

V1 hay V2?

Emulator V1 + Remoter

Mỗi game một cửa sổ riêng, cách ly tốt, điều khiển tập trung bằng Remoter. Tốn RAM hơn.

Emulator V2

Nhiều tab trong một cửa sổ, một tiến trình, nhẹ hơn. Lỗi nặng ở tầng Java có thể ảnh hưởng cả cửa sổ.

Tính năng

🗂️ Nhiều tab

Mỗi tab có thiết bị, dữ liệu lưu game và proxy riêng.

🌐 Proxy theo tab

HTTP và SOCKS5; gán riêng hoặc chia vòng từ kho proxy.

🔁 Đồng bộ thao tác

Phím và chuột ở một tab được nhân ra các tab đã chọn.

🧹 Dọn RAM

Dọn ngay hoặc tự dọn theo ngưỡng HEAP.

Kiểm tra file tải về

Mỗi bản phát hành có SHA256SUMS.txt, tính sau cùng trên đúng các file đăng.

# Linux
sha256sum -c SHA256SUMS.txt
# Windows (PowerShell)
Get-FileHash .\<tên-file> -Algorithm SHA256
