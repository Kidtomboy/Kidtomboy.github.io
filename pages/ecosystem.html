Hệ sinh thái Che779

Che779 là bộ giả lập J2ME gồm 4 repo. Hai repo Windows là gốc, hai repo còn lại đóng gói lại cho Linux và Android.

Windows

Che779-Emulator

Emulator V1 + Remoter. Mỗi game một cửa sổ, điều khiển tập trung.

 Windows

Che779-EmulatorV2

Emulator V2. Nhiều tab trong một cửa sổ.

▼ hai repo Windows là nguồn, hai repo dưới đây ghim (pin) phiên bản của chúng thay vì sao chép mã

Linux

Che779-Linux

Gói .deb / .tar.gz: V2 + V1 + Remoter Linux.

 Android

Che779-Android

APK, APK clone và script Termux chạy V2.

Quy ước chung

  • Phát hành bằng tag dạng v*. Có thể chạy thử quy trình ở chế độ dry-run (workflow_dispatch) mà không tạo release thật.
  • Mỗi release có SHA256SUMS.txt là file cuối cùng. Dùng trang Kiểm tra SHA-256 để đối chiếu.
  • Linux và Android ghim phiên bản của repo Windows qua EMULATOR_V1_REF / EMULATOR_V2_REF, không sao chép mã.
  • Quyết định thiết kế được ghi trong docs/DECISIONS.md của từng repo.
