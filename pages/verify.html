Kiểm tra SHA-256

Chọn file đã tải về và dán nội dung SHA256SUMS.txt của bản phát hành. File được tính hash ngay trên máy bạn, không gửi đi đâu.

Mở file SHA256SUMS.txt trong trang Releases rồi sao chép toàn bộ nội dung vào đây. Mỗi dòng có dạng hash tên-file.


Kiểm tra bằng dòng lệnh 
Windows (PowerShell):  Get-FileHash .\tên-file -Algorithm SHA256
Linux / Termux:        sha256sum -c SHA256SUMS.txt
